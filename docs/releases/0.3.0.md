# Falah 0.3.0

Falah 0.3.0 brings a simpler settings interface, more Quran and hadith sources, and better handling of incomplete upstream resources.

## Settings and library

- Reader, Library, and Advanced tabs with a filled active state and theme-aware surfaces.
- Flat sections without accordions, and a unified catalog for installed and available resources.
- Searchable Quran language selection, compact hadith language controls, and left-aligned dropdowns throughout the plugin.
- Source filters, clear installation status, and Install, Resume, Update, and Remove actions in each resource row.
- Settings search matches individual rows across all words in the query.

## Quran and hadith sources

- Quran Project translations in English, Bengali, and Urdu.
- Eleven Hadith Unlocked collections, preserving exact identifiers, narration chains, and provider-supplied grades.
- Hadith Unlocked fallback when the existing CDN fails or cannot represent an exact reference.
- Quran.com tafsir pagination and grouped-passage recovery, with coverage information for missing ayahs.
- A repeatable source audit script and a [documented audit](https://github.com/zubayrali/obsidian-falah/blob/0.3.0/docs/source-audit-2026-10-05.md).

The public source audit recorded 951 passing live checks. Authenticated Sunnah API checks were skipped without a key. Upstream gaps can still exist: Al-Sa'di had four unavailable passages in the audited Al-Baqarah resource. The library reports remaining gaps rather than treating them as complete text.

## Install or update

Download `main.js`, `manifest.json`, and `styles.css`, or extract `falah-0.3.0.zip`. Place the three files in `<vault>/.obsidian/plugins/falah/`, then reload Obsidian and enable Falah in **Settings → Community plugins**. When updating, replace only these files and keep your existing plugin data and downloaded resources.

Requires Obsidian 1.8.7 or newer. Core Quran text works offline; additional resources require a download before offline use. External services receive only the resource or reference requested, never your notes or vault contents.
